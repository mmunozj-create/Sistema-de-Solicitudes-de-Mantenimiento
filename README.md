## 📖 Descripción del Problema
Aplicación en consola desarrollada en Java para gestionar equipos, usuarios y solicitudes de mantenimiento. El sistema permite registrar incidentes, evitar duplicados, realizar búsquedas rápidas, mantener información ordenada y procesar solicitudes según su nivel de prioridad.

## 🛠️ Colecciones del Java Collections Framework Utilizadas
* **`ArrayList`**: Utilizada para mantener el registro general y secuencial de todas las solicitudes de mantenimiento.
* **`HashSet`**: Utilizada para controlar y evitar tipos de daño duplicados.
* **`HashMap`**: Utilizada para realizar búsquedas, actualizaciones y eliminaciones instantáneas mediante el código único de la solicitud.
* **`TreeSet`**: Utilizada para mantener las solicitudes ordenadas de forma natural.
* **`PriorityQueue`**: Utilizada para procesar las solicitudes atendiendo primero a las de mayor prioridad (urgentes).
